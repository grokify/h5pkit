## [v0.7.0] - 2026-10-19

### Highlights

- Likert questions on standard `H5P.MultiChoice`: build, validate, and score them by skill, and they play ungraded in any H5P player
- MultiChoice behaviour fields that default to true can now be set to false

### Added

- `Extension.Scoring` (`Scoring`, `NewLikertScoring`, `WithScoring`), with the `likert` method, a scale, and a reverse flag, validated by `Extension.Validate` ([`9367cba`](https://github.com/grokify/h5pkit/commit/9367cba))
- `NewLikertParams`, `QuestionSetBuilder.AddLikertQuestion`, and `ValidateLikertParams`; `QuestionSet.Validate` checks questions with Likert scoring ([`22b2ee7`](https://github.com/grokify/h5pkit/commit/22b2ee7))
- `LikertValue` and `QuestionSet.ScoreLikert`, returning a `LikertScore` with count, mean, and normalized score per skill ([`22b2ee7`](https://github.com/grokify/h5pkit/commit/22b2ee7))
- `schemas.Bool` for setting the pointer behaviour fields ([`9260682`](https://github.com/grokify/h5pkit/commit/9260682))

### Changed

- **BREAKING:** `schemas.Behaviour` fields `EnableRetry`, `EnableSolutionsButton`, `EnableCheckButton`, `RandomAnswers`, and `ShowScorePoints` are `*bool` instead of `bool` ([`9260682`](https://github.com/grokify/h5pkit/commit/9260682))

### Fixed

- Setting a MultiChoice behaviour field that defaults to true to false is written to JSON; it was dropped, so players used true ([`9260682`](https://github.com/grokify/h5pkit/commit/9260682))

### Documentation

- Likert questions and the `scoring` field in the extensions guide ([`13dea9d`](https://github.com/grokify/h5pkit/commit/13dea9d))
- The typed-questions guide shows the pointer behaviour fields and lists only fields the type has ([`9260682`](https://github.com/grokify/h5pkit/commit/9260682))
- INIT-H5PKIT-001 Likert scoring phase and the v0.7.0 release item ([`d5a55cb`](https://github.com/grokify/h5pkit/commit/d5a55cb))
- v0.7.0 release notes

### Tests

- Likert scoring, validation, and JSON round trip, and a runnable Likert scoring example ([`11c2230`](https://github.com/grokify/h5pkit/commit/11c2230))

## [v0.6.0] - 2026-10-19

### Highlights

- Question bank registry: banks, immutable published versions, licenses, lineage, and a `Store` interface with an in-memory store and a conformance suite
- Question metadata gains relative difficulty, skills, and standards, under the renamed `h5pkit` extension key
- Export a bank version to an `.h5p` package and import `.h5p` question sets
- Documentation reorganized into guides, design, specifications, and releases, with a question banks guide

### Added

- `Extension.DifficultyScore`, `Skills` (`SkillRef`), and `Standards` (`StandardRef`), validated by `Extension.Validate` and `QuestionSet.Validate` ([`612e5a4`](https://github.com/grokify/h5pkit/commit/612e5a4))
- `registry` types: `Bank`, `BankVersion`, `License`, `Lineage`, `Status`, `Relation`, and `ListFilter` ([`ca82eed`](https://github.com/grokify/h5pkit/commit/ca82eed))
- `registry.Store` with `MemoryStore`, and the `registry/registrytest` conformance suite for other implementations ([`1fac3b2`](https://github.com/grokify/h5pkit/commit/1fac3b2))
- Publishing with skill and standard unions, `ErrImmutable`, new versions from existing ones, forks with lineage, and `Descendants` ([`4e343bb`](https://github.com/grokify/h5pkit/commit/4e343bb))
- `ExportQuestionSet`, `ExportPackage`, `WritePackage`, and `ImportPackage` for `.h5p` interop, plus `Unions` and `CompareVersions` ([`bbe2b7a`](https://github.com/grokify/h5pkit/commit/bbe2b7a))

### Changed

- **BREAKING:** The question metadata block is read and written only under the `h5pkit` extension key; the `h5pGo` key is no longer read ([`0abbf90`](https://github.com/grokify/h5pkit/commit/0abbf90))
- **BREAKING:** `H5PGoExtension` is renamed `Extension` and `NewH5PGoExtension` is renamed `NewExtension`; the old names are removed ([`cc1ffe4`](https://github.com/grokify/h5pkit/commit/cc1ffe4))
- The `go` directive is 1.26 ([`995e6d5`](https://github.com/grokify/h5pkit/commit/995e6d5))

### Fixed

- `QuestionSet.Validate` names the index of a bad feedback range as a number ([`43b1dcd`](https://github.com/grokify/h5pkit/commit/43b1dcd))

### Documentation

- Extensions guide covering every field, the relative-difficulty rule, and the `h5pkit` key ([`27db33f`](https://github.com/grokify/h5pkit/commit/27db33f))
- Question banks guide and standards reference ([`0c33584`](https://github.com/grokify/h5pkit/commit/0c33584))
- Site reorganized into `docs/guides/`, `docs/design/`, `docs/specs/`, and `docs/releases/`, with index pages and the changelog ([`ef74eec`](https://github.com/grokify/h5pkit/commit/ef74eec))
- INIT-H5PKIT-001 specifications for the question bank registry and extensions ([`c979101`](https://github.com/grokify/h5pkit/commit/c979101))
- v0.6.0 release notes

### Tests

- A runnable registry example ([`3503bf2`](https://github.com/grokify/h5pkit/commit/3503bf2))
- Removed a test that read a file outside the repository ([`90b5989`](https://github.com/grokify/h5pkit/commit/90b5989))

### Infrastructure

- Shared CI, lint, and CodeQL workflows updated ([`a0b8029`](https://github.com/grokify/h5pkit/commit/a0b8029))

## [v0.5.0] - 2026-03-22

### Highlights

- Module renamed from `h5p-go` to `h5pkit`
- TypeScript quiz editor (`@grokify/h5p-editor`) for browser-based editing

### Added

- TypeScript quiz editor package in `ts/packages/editor/`
- React component `QuizEditor` with ref-based API
- Vanilla JS API via `createQuizEditor()` for CDN usage
- Multiple Choice, True/False, Fill in Blanks question editors
- Undo/redo support for editing operations
- Real-time validation with detailed error messages
- Light and dark theme support

### Changed

- Renamed module from `github.com/grokify/h5p-go` to `github.com/grokify/h5pkit`
- Renamed repository from `h5p-go` to `h5pkit`

### Documentation

- TypeScript editor documentation in `docs/ts-editor/`
- Updated homepage to feature both Go SDK and TypeScript editor
