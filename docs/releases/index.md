# Releases

Release notes, one file per version, newest first. The
[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.7.0](v0.7.0.md), adds Likert questions on standard
`H5P.MultiChoice` and makes the MultiChoice behaviour fields that default to
true settable to false. Those fields are now `*bool`, which is breaking; read
its upgrade notes first.
