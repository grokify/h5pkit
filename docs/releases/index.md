# Releases

[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.6.0](v0.6.0.md), adds the question bank registry and
relative difficulty, skills, and standards on question metadata, and renames
the metadata key to `h5pkit`. The rename is breaking; read its upgrade notes
first.
